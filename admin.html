Paste Data

Paste any supported APA report here. First row = headers. Slate inspects the headers and auto-routes to the right importer. Currently selected session: —.

Each paste is identified by its header row. See the Reports card above for the full list and freshness status.

Supported player columns: Member Number, First Name, Nickname, Last Name, Email Address, Cell Phone, Home Phone, Work Phone, Alt Phone, Gender, 8-Ball Skill Level, 9-Ball Skill Level, Address 1, Address 2, City, State, Zip, Membership Revoked, Membership Promotion, Period Joined, Referred By, Date Marked Paid, Past Due, Deceased, Member Type, Date Started, Last Date Played 8-Ball, Last Date Played 9-Ball, Member Status. Unmapped columns are ignored.

County Lookup

Fills in missing county on player records using zippopotam.us (zip → lat/long) + FCC Census geocoder (lat/long → county). Free, no API keys, runs in your browser. One lookup per unique zip so 5,000 players with 600 unique zips = 600 HTTP calls.

PDF Import

Drag & drop (or click to browse) a Team Screen PDF. One team per page. Source: Nexus → Teams → Report List → Team Screen. Upserts teams and rebuilds Member rosters from each page's roster.
v1.8 workflow: Import Team Screen FIRST, then paste Team Data. Team Data captain resolution looks up captain names against each team's own roster (not a global player index), so a team must have its roster loaded before its captain can be resolved. Re-importing Team Screen automatically re-resolves captain rows: any captain whose member# vanished from the new roster is matched by name against the new roster, and the whole import hard-aborts (with no DB changes) if any name can't be resolved.
