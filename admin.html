Paste Data

Paste any supported APA report here. First row = headers. Slate inspects the headers and auto-routes to the right importer. Currently selected session: —.

  • Player Data — any subset of player columns. Merges on Member Number. Run the "Current Player Addresses" export one time, "Player Details" (SL + phone) another, the membership status export a third; each run merges into the player record.
  • Division Listing — imports/updates divisions for the current session (division #, name, format, night, start date, team count, weeks, fees). Operator stays NULL; assign on the Divisions tab.
  • Team Data — imports/updates teams with their captains, co-captains, and session stats.
  • Team Bonus Points — updates the bonus-point total on existing teams.

Supported player columns: Member Number, First Name, Nickname, Last Name, Email Address, Cell Phone, Home Phone, Work Phone, Alt Phone, Gender, 8-Ball Skill Level, 9-Ball Skill Level, Address 1, Address 2, City, State, Zip, Membership Revoked, Membership Promotion, Period Joined, Referred By, Date Marked Paid, Past Due, Deceased, Member Type, Date Started, Last Date Played 8-Ball, Last Date Played 9-Ball, Member Status. Unmapped columns are ignored.

County Lookup

Fills in missing county on player records using zippopotam.us (zip → lat/long) + FCC Census geocoder (lat/long → county). Free, no API keys, runs in your browser. One lookup per unique zip so 5,000 players with 600 unique zips = 600 HTTP calls.

PDF Import

Drag & drop (or click to browse) any supported APA PDF. Slate inspects the first page, figures out which report it is, and routes it to the right importer. Divisions import untagged — assign CR or SPM on the Divisions tab after.

  • Team Screen — one team per page. Source: Nexus → Teams → Report List → Team Screen. Upserts teams & rebuilds Member rosters. Captain/Co-Captain rows from Team Data paste preserved.
  • All Division Information List — full division directory. Source: Nexus → Divisions → Report List → Division Information List by Status. Upserts divisions with name, format, team count. Operator stays NULL on import; set it per-division on the Divisions tab.
