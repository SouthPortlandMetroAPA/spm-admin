How to paste

From the APA admin web interface, select a report’s table rows, Ctrl+C copy, and paste into the matching box below. The tool auto-detects which report you pasted by its header row, previews the parse, and commits on confirm.

  • Divisions & teams are scoped to the current session (shown in the pill above).
  • Player records are global (not session-scoped) — keyed by APA member number.
  • Captains / co-captains from Team Data paste are resolved to a player record by name; unresolved names show as "unmatched" in Email HQ.
